# EventsService

Клиентский сервис аналитических событий для Unity 2021.3: надёжная доставка событий на сервер с офлайн-буферизацией. Решает типовую задачу мобильной аналитики: не терять события при отсутствии сети и не спамить сервер по одному событию.

## Как работает

1. `TrackEvent(type, data)` сохраняет событие на диск (`FileHelper`), поэтому события переживают закрытие приложения и офлайн.
2. Фоновый цикл на UniTask собирает события в батчи с ограничением по размеру (`maxSendingBytes`) и отправляет POST-запросом (`WebRequest`).
3. Между отправками выдерживается cooldown; неотправленные батчи остаются на диске и уходят при следующей попытке.
4. Файлы удаляются только после подтверждённой доставки.

## Настройки (инспектор)

- `serverUrl`: адрес приёмника событий (для теста подойдёт https://posttestserver.dev).
- `cooldownBeforeSendSecond`: пауза между отправками.
- `maxSendingBytes`: максимальный размер батча.
- `sendTimeoutSecond`: таймаут запроса.

## Стек

Unity 2021.3, C#, UniTask, UnityWebRequest, JSON-сериализация.
